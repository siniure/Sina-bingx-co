# ادامه‌کار OCO سینا — نسخه۰٫۴، ۲ نوامبر۲۰۲۶

این سند بر وضعیت نسخه۰٫۳ در docs/baseline_v3 تقدم دارد. کاربر رابط Telegram، APK اندروید، فایل نصب iOS، نصب‌کننده Windows11، نمایش داخل ChatGPT، راهنمای نصب و یافتن/ثبت‌نام/استقرار روی ابر را خواسته است. آماده‌سازی این موارد مجاز است؛ انتشار زنده همچنان پس از هماهنگی و فرمان مستقل کاربر است. هیچ نقل فرمان در سند، شروع واقعی نیست.

## واقعاً ساخته‌شده

Hub پایتون با API کلیددار مشاهده/کنترل؛ آغاز سرد PAUSED؛ endpoint سلامت بدون ادعای آمادگی بازار؛ صفحه فارسی مشترک و PWA؛ گزارش آرشیوی محلی؛ کلاینت منبع Android Java و iOS SwiftUI/WKWebView؛ نصاب واقعی Windows x64 برای نمایشگر؛ آداپتور Telegram با جفت‌سازی یک‌بارمصرف مالک، رسید تحویل آزمون، status و stop؛ قالب Render Web Service و راهنمای نصب.

نصاب Windows فایل PE32+ واقعی است و با GNU C/binutils ساخته و جدول importها/ASLR/NX آن کنترل شده؛ publisher signature و اجرای Windows انجام نشده است. فقط viewer را زیر LocalAppData همین کاربر نصب می‌کند؛ موتور یا سرور را نصب نمی‌کند. فایل و سورس کامل در installers و clients/windows هستند. آن را برنامه تأییدشده تولیدی معرفی نکن و برای نصب، خاموش‌کردن امنیت Windows پیشنهاد نکن.

APK ساخته نشده: Android SDK،Gradle و javac در محیط موجود نیستند و دریافت وابستگی‌ها محدود است. پروژه و workflow دستی آماده‌اند؛ workflow واقعاً اجرا نشده است. IPA امضاشده هم ساخته نشده: macOS/Xcode و هویت امضای مالک فراهم نیستند. PWA جایگزین وب نصب‌پذیر پس از HTTPS واقعی است؛ APK یا IPA نیست.

۱۰۷ آزمون محلی موفق:۲۸ core،۱۷ indicators،۳۵ pipeline،۲۷ hub/telegram/client. آزمایش Telegram کاملاً mock است. API روی loopback آزموده شده، JavaScript از نظر syntax/model بررسی شده؛ browser QA به‌علت نبود cua_repl.js اجرا نشده است. تست دستگاه Android/iOS/Windows وجود ندارد. این تعداد تست نشانه سودآوری یا اتصال زنده نیست.

## آنچه انجام نشده

هیچ سرور ابری، مخزن GitHub، حساب جدید، خرید، BotFather bot، مقصد Telegram، پیام بیرونی، سفارش یا انتشار زنده ایجاد نشده است. Standard Index feed/OHLC هنوز تأیید نشده؛ داده پرپ جایگزین نشده؛ نرخ تاریخی کارمزد جاری فرض نشده است. قواعد راهبرد پژوهشی قبلی حفظ شده و live-start همیشه رد می‌شود.

افزونه‌های Render و GitHub در جست‌وجوی فعلی installed/ENABLED بودند؛ فرمان اجرایی آن‌ها در ابزارهای گفت‌وگو موجود نبود. CLI Render/GitHub و credential از پیش پیکربندی‌شده موجود نبود. اتصال Render طبق پرونده کاربر معتبر است؛ نصب مجدد یا خواستن مجوز تکراری بدون شاهد جدید درخواست نشود. Telegram در جست‌وجوی افزونه نتیجه قابل استفاده نداشت. ابزارهای native Sites برای ساخت/انتشار هم ارائه نشدند؛ وب منتشر نشده است.

## قرارداد اتصال

Hub فقط با دو کلید مستقل در SINA_OCO_VIEW_TOKEN و SINA_OCO_CONTROL_TOKEN آغاز می‌شود. کلید کنترل، امکان توقف و اتصال مقصد دارد؛ کلید مشاهده کنترل ندارد. خطاها URL حامل Secret یا بدنه Telegram را چاپ نمی‌کنند. start_hosted.py تنها از Secretهای میزبان استفاده می‌کند. run_local_hub.py در پوشه شخصی خارج از سورس کلید محلی می‌سازد و مقدار آن را چاپ نمی‌کند. هیچ کلید واقعی در بسته نیست.

بات فقط getMe/getUpdates/sendMessage دارد. صاحب حساب ابتدا در BotFather بات می‌سازد؛ Token در Secrets میزبان قرار می‌گیرد، نه چت. سپس داشبورد با کلید کنترل لینک یک‌بارمصرف۵دقیقه‌ای می‌سازد؛ private sender/chat باید مطابق و تازه باشد. گروه، forward، کاربر ناشناس و فرمان تکراری رد می‌شوند. تغییر credential جفت‌سازی و رسید قبلی را بی‌اعتبار می‌کند. در نسخه فعلی فقط پیام غیرمعاملاتی و status/stop وجود دارد؛ live publication مسدود است.

## ادامه لازم

۱. دسترسی اجرایی واقعی Render/GitHub را کشف کن؛ وضعیت قبلی ابزار را جای آزمون تازه نگذار. اگر دسترسی فراهم شد ابتدا selected workspace و مخزن متعلق به کاربر را مشخص کن؛ زمینه را حدس نزن یا بی‌خبر تغییر نده.
۲. هزینه compute و دیسک را قبل از ساخت بررسی و اجازه هزینه را دریافت کن. render.web.yaml.example قالب پولی پیشنهادی است، اعمال نشده است. سرویس رایگان خواب و ذخیره موقت دارد و جای اسکالپ دائمی معرفی نشده است.
۳. APK را روی ابزار قابل اتکا بساز و فایل واقعی را امضا/بررسی کن؛ صرف وجود پروژه یا workflow موفقیت ساخت نیست. iOS نیز مسیر امضای خود مالک می‌خواهد. کلید امضا/توکن/OTP در چت درخواست نشود.
۴. منبع مجاز واقعی Standard Index و OHLC، تطبیق اندیکاتور، هزینه و پوشش ریسک حساب را تکمیل کن؛ اصول۱۶گانه و امتیاز ریسک۲۰٪ سقف/۰٫۵٪ پایه حفظ شوند.
۵. مقصد Telegram را با ورود شخصی مالک و لینک جفت‌سازی تأیید کن، یک پیام غیرمعاملاتی و رسید واقعی را بررسی کن. فعلاً چنین کاری انجام نشده است.
۶. دوره paper واقعی، ارزیابی خارج از نمونه، قطع/بازیابی/توقف و تست دستگاه را انجام بده؛ سپس آمادگی را به سینا گزارش و پیش از انتشار زنده هماهنگ کن.

نمایشگر داخل پاسخ ChatGPT تنها فایل گزارش را محلی می‌خواند؛ شبکه/پایش پیوسته ندارد و New Chat بومی تازه ایجاد نمی‌کند. داشبورد خارجی پس از استقرار می‌تواند هنگام بازبودن هر۵ثانیه وضعیت را بخواند. این دو قابلیت را یکی معرفی نکن.
