# قدم بعدی سینا — نسخه۰٫۴

راهنمای کامل و وضعیت واقعی فایل‌های نصب در INSTALL_GUIDE_FA.md است. نسخه Windows نمایشگر است؛ APK و IPA هنوز ساخته نشده‌اند. سرویس یا بات واقعی نصب نشده است.

حساب Render را دوباره ثبت‌نام نکن؛ اتصال قبلی طبق پرونده برقرار است. ابزار اجرای آن در این گفت‌وگو وجود نداشت، پس workspace و مخزن و قیمت و استقرار هنوز بررسی عملی نشده‌اند. از نصب دوباره یا دادن مجوز تکراری نتیجه قطعی برداشت نشود.

برای اتصال واقعی Telegram، BotFather باید از حساب مالک بات را بسازد و Token فقط در Secrets میزبان قرار گیرد. پس از آن لینک جفت‌سازی داشبورد به همان حساب خصوصی متصل می‌شود. هیچ Token یا رمز را در چت نفرست.

برای APK به اجرای واقعی دستور ساخت/CI و بررسی فایل خروجی نیاز است؛ برای IPA به Xcode و امضای مالک. مسیر وب نصب‌پذیر بعد از داشتن آدرس HTTPS سرور، گزینه مشترک گوشی‌هاست. هیچ‌کدام فعلاً داده زنده ایجاد نمی‌کنند.

کد، نصاب آزمایشی و تنظیمات بررسی‌پذیر آماده‌اند. پیش از استقرار پولی، هزینه و محل باید مشخص شوند؛ پیش از شروع انتشار واقعی نیز آماده‌سازی منبع و آزمون‌ها و هماهنگی نهایی لازم است.
