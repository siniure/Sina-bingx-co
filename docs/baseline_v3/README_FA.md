# OCO خودکار سینا — نسخه ۰٫۳؛ اجرای پژوهشی، انتشار زنده غیرفعال

تاریخ ادامه: ۲ نوامبر۲۰۲۶؛ گزارش‌ها Europe/Istanbul. دامنه: BTCUSDT، BingX Standard Futures / Index، تحلیل و پیشنهاد OCO.

پرونده تکمیلی کاربر درباره اتصال Render مبناست. راهنمای قدیمی Railway در docs/baseline_v2 حفظ شده و دستور اتصال مجدد نیست. از CORE_README_FA.md فقط برای هسته قدیمی core.py استفاده کنید؛ دستور اجرای جدید در این صفحه است.

## کار اضافه‌شده

- موتور عددی شش تایم‌فریم، EMA، MACD/ATR/RSI، بولینگر، پیوت علّی و شکست/بازآزمایی بسته.
- SL ساختاری با حاشیه یک‌باره، TP پیش از هدف، محدوده ورود و نسبت خالص در نامساعدترین قیمت.
- ریسک فرضی با Equity تازه، مواجهه‌های باز، بودجه مشترک، گام مقدار و سقف ثابت۲۰٪؛ حساب ناقص حجم ندارد.
- worker بازپخش محلی، دفتر SQLite، توقف بین پردازه‌ها، حذف تکرار پس از راه‌اندازی مجدد، انقضا و منع احیای طرح باطل‌شده.
- گزارش فارسی، جدول تایم‌فریم/اندیکاتور/ریسک و کادر مستقل فقط عدد برای طرح آزمایشی معتبر.
- کلاینت فقط‌خواندنی محدود Standard برای سه مسیر مستند حساب؛ در worker متصل یا فراخوانی نشده است.
- قالب قابل بررسی Render؛ بدون استقرار، خرید یا انتخاب workspace.

## اجرای محلی

Python۳٫۱۰ یا جدیدتر با کتابخانه استاندارد؛ روی محیط Linux آزموده شده است. نصب بسته خارجی یا API Key برای آزمون لازم نیست.

```bash
python -m unittest discover -s tests -v
python -m oco status
python scripts/run_demo.py --output-dir demo-result
```

demo فقط داده ساختگی تولید می‌کند، گزارش محلی می‌نویسد و دفتر را در پایان PAUSED می‌گذارد. تکرار همان نمونه، طرح متوقف‌شده را احیا نمی‌کند؛ برای تجربه مستقل از پوشه خروجی تازه استفاده شود. نتایج تست در TEST_REPORT.txt هستند؛ تعداد آزمون، نرخ برد یا اتصال زنده نیست.

آزمایش مستقیم بازپخش در پوشه مستقل:

```bash
python -m oco paper-start --data-dir trial
python -m oco replay --snapshot demo-result/input.synthetic.json --data-dir trial
python -m oco stop --data-dir trial
```

paper-start فقط پیش‌نمایش آفلاین را مجاز می‌کند. فرمان live-start باید BLOCKED شود؛ تغییر true در فایل ورودی نیز فید را زنده نمی‌کند. state.json قدیمی همچنان enabled=false است؛ برنامه جدید حالت خود را جداگانه در journal.sqlite3 و در ابتدا PAUSED می‌سازد.

worker پس از تأمین ورودی آزمایشی زمان‌دار:

```bash
python -m oco worker --snapshot /var/data/oco/input.json --data-dir /var/data/oco --interval 5
```

این worker شبکه نمی‌خواند؛ فایل‌های بازپخش را دوره‌ای بررسی می‌کند. فایل مصنوعی تاریخ‌دار بعد از کهنه‌شدن نباید از worker عبور کند. قطع ورودی یا تازگی نامعتبر، پیش‌نمایش جاری را کنار می‌گذارد و حالت را PAUSED می‌کند. SIGTERM توقف منظم ثبت می‌کند. اجرای این فرایند موقت در چت، سرویس۲۴ساعته نیست.
