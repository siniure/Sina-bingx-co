# OCO سینا — نسخه۰٫۴٫۱؛ بازبینی اتصال و ساخت، انتشار زنده غیرفعال

دامنه: BTCUSDT، BingX Standard Futures / Index؛ تحلیل و هشدار. بازار معتبر هنوز متصل نیست. کاربر ساخت تلگرام، برنامه‌های موبایل/ویندوز، نمایش داخل ChatGPT و استقرار را خواسته است. این نسخه اجزای قابل ساخت را اضافه می‌کند و خروجی‌های واقعاً ساخته‌شده را از موارد نیازمند ابزار/احراز هویت جدا ثبت می‌کند.

## خروجی موجود

| بخش | وضعیت واقعی |
|---|---|
| Hub و API | ساخته و محلی با کلید مستقل مشاهده/کنترل آزموده شده |
| وب و PWA | رابط فارسی ساخته‌شده؛ نصب وب بعد از HTTPS واقعی |
| Windows11 x64 | EXE نمایشگر بازسازی؛ نصب مرحله‌ای/rollback و CI اجرای Windows آماده؛ اجرا و امضای ناشر هنوز تأیید نشده |
| Android | ساخت دستی CI برای APK debug و release با Secretهای مالک؛ APK هنوز تولید نشده |
| iOS | پروژه Xcode و CI کامپایل Simulator؛ IPA دستگاه امضاشده تولید نشده |
| Telegram | آداپتور جفت‌سازی مالک، status/stop و رسید آزمون؛ اتصال واقعی انجام نشده |
| ChatGPT | نمایشگر گزارش آرشیوی در پاسخ؛ دریافت پیوسته شبکه در آن سطح موجود نیست |
| Render | قالب web service/دیسک/Secrets؛ استقرار و هزینه‌ای ایجاد نشده |

راهنمای قدم‌به‌قدم در INSTALL_GUIDE_FA.md است. برای اجرا، استفاده از همین سند را بر راهنمای نسخه‌های قدیمی مقدم بدان. هیچ فایل APK یا IPA ساختگی، تغییرپسوندشده یا نامعتبر به‌عنوان اپ نصب‌شدنی ارائه نشده است.

## اجرای محلی Hub

Python۳٫۱۰ یا جدیدتر، فقط کتابخانه استاندارد برای سرور/موتور. دستور از ریشه بسته:

```text
python scripts/run_local_hub.py
```

کلیدهای مشاهده و کنترل به‌صورت تصادفی در پوشه شخصی خارج از سورس تولید می‌شوند؛ مقدار آن‌ها در خروجی چاپ نمی‌شود. راهنمای محل و ورود در INSTALL_GUIDE_FA.md آمده است. کلید یا Bot Token را در چت نفرست. Hub از ابتدا PAUSED است و شروع زنده مسدود می‌ماند.

```text
python -m unittest discover -s tests -v
python -m oco status
python scripts/run_demo.py --output-dir demo-result
```

نمونه demo ساختگی است؛ گزارش محلی دارد و با PAUSED پایان می‌یابد. server و bot هیچ سفارش صرافی یا Fill/PnL واقعی تولید نمی‌کنند. فید معتبر Standard، هزینه و حساب واقعی و بررسی خارج از نمونه همچنان لازم‌اند.

## نقش کلاینت‌ها

رابط موبایل/ویندوز، نمایشگر سرور مشترک است. نصب نمایشگر به‌تنهایی موتور تحلیل یا فید بازار ایجاد نمی‌کند. Windows EXE فقط فایل‌های نمایشگر همین کاربر را نصب می‌کند؛ Python و سرور را همراه ندارد. نسخه وب فایل محلی را هم باز می‌کند. Android و iOS پس از ساخت درست، نشانی HTTPS سرور را می‌گیرند.

در برنامه متصل، وضعیت هر۵ثانیه درخواست می‌شود؛ این به‌معنی فید زنده تأییدشده نیست. زمان سرور و زمان داده بازار جدا هستند. قطع ارتباط اعداد فعال را پنهان می‌کند؛ service worker فقط پوسته را نگه می‌دارد و API یا کلید را cache نمی‌کند.

## اتصال تلگرام

از حساب خود صاحب بات در BotFather ایجاد می‌شود. پس از قرار دادن TELEGRAM_BOT_TOKEN در Secrets میزبان، داشبورد با کلید کنترل پیوند یک‌بارمصرف می‌سازد؛ صاحب حساب در گفت‌وگوی خصوصی آن را تأیید می‌کند. پیام forwardشده، گروه، کاربر دیگر یا پیام قدیمی کنترل را فعال نمی‌کند. رسید sendMessage باید با chat_id همان مالک تطبیق داشته باشد. تغییر credential بات، جفت‌سازی و رسید قبلی را باطل می‌کند.

کارکرد فعلی بات: جفت‌سازی، پیام آزمون غیرمعاملاتی، /status و /stop. سینا گزارش کرده بات را در BotFather ساخته است؛ هنوز Token در میزبان پیکربندی نشده، مقصد جفت نشده و پیامی واقعی از این کد ارسال نشده است. انتشار زنده سیگنال در این نسخه مسدود است.

## بازبینی این نسخه

۱۱۸ آزمون محلی موفق است؛ گزارش در TEST_REPORT.txt. کنترل انقضا/ابطال هنگام نمایش، تطبیق گزارش با آرشیو، کلیدهای بدون فاصله/کنترل‌کاراکتر، خطای PORT، مهلت و خطاهای امن Telegram اصلاح شده‌اند. scripts/check_host.py بررسی امن تنظیمات و در صورت درخواست، getMe/getWebhookInfo بدون ارسال پیام را آماده دارد. این آزمون‌ها جای اجرای CI، تست دستگاه، اتصال واقعی و ارزیابی راهبرد را نمی‌گیرند. AUDIT_REPORT_FA.md حدود دقیق شواهد را ثبت می‌کند.

## میزبانی

render.web.yaml.example قالب پیشنهادی است؛ خودش حساب، مخزن یا سرویس نمی‌سازد. از حساب Render موجود باید استفاده شود. نصب افزونه Render و GitHub دیده شد؛ ابزار اجرای حساب/CLI آن‌ها در این گفت‌وگو موجود نبود، پس ثبت‌نام و استقرار انجام نشد. workspace و مخزن از نام حساب حدس زده نشده‌اند. قبل از منبع پولی، محل و هزینه واقعی باید بررسی و تأیید شوند.
